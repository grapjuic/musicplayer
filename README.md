# studio ghibli music player (spirited away themed)
a cute desktop music player built with Electron, HTML, CSS, and JavaScript — featuring a spirited away theme and spotify integration

## features

- spotify authentication 
- browse your Spotify playlists
- see currently playing song (title, artist, album cover)
- play, pause, skip, and go back
- minimalist and aesthetic interface
